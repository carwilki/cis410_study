# CS410 Exam Study Guide

A self-contained study guide for the CS410 (Text Information Systems) exam, covering Weeks 1–9: topic summaries, worked examples, and self-check quizzes with step-by-step solutions.

## Usage

Download `exam-study-guide.html` and open it in any modern browser. It is a single HTML file with no build step or server; fonts (Google Fonts) and MathJax (cdnjs) load from public CDNs, so an internet connection is needed for math and typography. Quiz progress is saved in your browser's local storage.

To host it, drop the file on any static host (e.g. GitHub Pages, renaming it to `index.html`).
